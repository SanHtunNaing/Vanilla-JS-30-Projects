Study Guide: Key Concepts

Reference Memory Pointer

Assigning an Object or Array (b = a) does not copy data. Both point to the same memory.

Shallow Copy 1-Level Copy

Methods like [...arr] copy 1 level. Inner nested objects still share memory.

Deep Copy Full Isolation

Methods like structuredClone() copy all nested levels completely.
