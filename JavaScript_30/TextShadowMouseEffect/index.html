Deep Dive Study Guide

1. Offset & Target Coordinates Calculation

e.offsetX and e.offsetY return mouse coordinates relative to the targeted element. When hovering over inner elements (e.g., <h1>), this stays as .hero, but e.target shifts. We normalize coordinates by adding target.offsetLeft and target.offsetTop.

2. Dynamic Math Shadow Displacement

We calculate maximum displacement (walk radius) relative to window width and height. Centering the origin at (0,0) requires shifting coordinates by half width/height: (x / width * walk) - (walk / 2).
