LOCAL STORAGE TAPAS

Persist your data with LocalStorage & Event Delegation

Deep Dive Study Guide

1. LocalStorage Data Persistence

In-memory JavaScript variables (e.g., let items = []) clear out as soon as the page is reloaded. LocalStorage allows us to save data across browser sessions.

  • Key-Value Pair: Stores data as key-value pairs inside the browser.
  • Strings Only: LocalStorage can only store plain text/strings. Direct object storage results in corrupted data like [object Object].
  • JSON.stringify(): Converts JavaScript objects or arrays into a JSON string before saving: localStorage.setItem('items', JSON.stringify(items))
  • JSON.parse(): Converts stored JSON strings back into usable JS objects/arrays: JSON.parse(localStorage.getItem('items'))

2. Event Delegation Listening on Parent

The Problem: When the page loads, dynamic child elements (e.g., <li> or <input>) don't exist yet, so attaching direct event listeners directly to them fails.

The Solution: Attach a single listener to a permanent parent element (<ul class="plates">) instead.

  • Event Bubbling: Clicks on child elements bubble up to the parent element (<ul>).
  • Target Inspection: The parent checks e.target to see exactly which element fired the event.
  • Pattern Match: e.target.matches('input') verifies if the clicked element is specifically an <input> (checkbox).

Data Flow Execution Lifecycle

  1. User submits item → Pushed to items array.
  2. Saved → localStorage.setItem('items', JSON.stringify(items))
  3. Rendered → populateList() builds HTML inside <ul>.
  4. Toggled → Event Delegation catches click on <ul>, updates items[index].done, and syncs LocalStorage.
