Tally String Times

Extracting and reducing video durations into total time

Deep Dive Study Guide

1. NodeList to Array Array.from()

document.querySelectorAll() returns a NodeList. We use Array.from() or spread syntax [...nodes] to enable array methods like .map() and .reduce().

2. String to Seconds Map & Reduce

We split time strings ("5:43") into minutes and seconds, convert them to total seconds via parseFloat(), and sum them using .reduce((total, secs) => total + secs, 0).

3. Modulo Math Breaking Down Total Seconds

Using Math.floor() and the modulo operator (%), we convert cumulative seconds back into HH:MM:SS format.
