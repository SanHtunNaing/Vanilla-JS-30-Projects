Real-time video processing & custom filters

Deep Dive Study Guide

1. MediaDevices navigator.mediaDevices.getUserMedia()

Requests permission to access the webcam video stream. The returned stream is attached directly to the HTML5 <video> element.

2. Canvas Rendering ctx.drawImage()

Continuously paints video frames onto an HTML5 <canvas> element. Pixel manipulations (Red Split, Green Screen) modify raw RGBA image data array buffers.
